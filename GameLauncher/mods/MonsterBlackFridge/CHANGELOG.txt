DOCUMENTATION PATCH — 2026-10-16
Safe-removal instructions are now visible in REMOCAO-SEGURA.md and the main readme of each of the five appearance packages. Monster's obsolete disable-and-restart instruction is corrected. The included Recovery guide remains unchanged.
These current removal instructions supersede removal wording in the historical notes below. Setting 0% alone does not migrate unseen areas or stored references. Recovery must remain active while those references or retained Dr Pepper types remain. This documentation patch does not change gameplay files, art, saved identifiers or game-mod versions.

- Shorter fridge and freezer hover labels in all 26 supported languages.
- Refresh localized mod menu text after the game language is initialized.

1.4.0 - Ten appearance percentages
Expanded the Sandbox selector to exactly ten choices: 1%, 5%, 10%, 15%, 25%, 35%, 50%, 75%, 90% and 100%. Default remains 100%. Updated all ten labels and option tooltips, legacy-state text and Mods-menu descriptions across all 26 supported language selections. Furniture and compartment names were reviewed and retained.
Preserved the existing Distribution save key and IDs 1-5; appended IDs for the new probabilities. Native storage is now an integer ID with a ten-choice visual selector in new-game and hosting menus. Existing 0% saves retain their value until the user explicitly selects a new option; 0% is not an eleventh selectable option. Verified binary migration from all five old enum values to the new storage, native Lua export and save/load of all IDs.
Validated 220,000 generated objects across the ten probabilities plus legacy zero, all four orientations, movable appearance persistence, UI selection and hover descriptions in 26 locales and both Coca/Monster load orders. In-game rendering, sounds, green light, inventory and texture assets are unchanged. Fresh live multiplayer testing was not performed for this release.

1.3.4 - Multilingual interface
Localized sandbox labels and option tooltips, container names, compartment tooltips, movable furniture names, and Mods-menu name/description. Added the requested languages, including all three Latin American Spanish selections. Fixed the Coca-Cola movable translation key. Follows the game language; gameplay, textures, sounds and saved identifiers are unchanged.

1.3.3 - Sandbox variety, green lighting and display fixes

Added a native Sandbox dropdown with 0%, 25%, 50%, 75% and 100% Monster appearances (100% default), with English and Portuguese labels. The appearance choice follows transported furniture. Other industrial fridge variants retain their original appearance and lighting.

Powered Monster fridges emit a soft green light in all four orientations, more noticeable in dark rooms. Grid/generator power and Nick's Turn Off Fridges plug state control light and hum. Lights are cleaned up after removal/unloading and original lighting is restored after a Sandbox appearance change.

Fixed overlapping glass/stock rendering: the Monster sprites no longer schedule the automatic illuminated front pass on top of their custom stock layer. The B42 engine also redraws the stock overlay in that pass; disabling only the two independent Monster front flags removes the duplicate pass while preserving Nick's unplug marker and vanilla fridge flags. Retains the native depth mappings for all 30 textures.

Added dedicated fridge/freezer inventory icons, the Monster Fridge container title, and the new user-selected Mods-menu icon. Individual nearby spatial hum emitters use the original game sounds and restore correctly after plugging back in. Stock visuals still support six levels while powered or unpowered.

Updated the English Workshop gallery and promotional image. Storage capacities, cooling, items, interaction sounds and the original world textures are unchanged. Restart the game after updating. Existing saves are supported; dedicated-server visual validation remains pending.
